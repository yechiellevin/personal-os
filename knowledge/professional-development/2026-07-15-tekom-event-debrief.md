# Tekom event debrief

**Event date:** 2026-07-15  
**Debrief completed:** 2026-08-06

## Presentation 1 — Jeff Klein, Thales

Technical content now needs to be structured for both human readers and LLM consumption. Poor hierarchy, scattered information, and weak heading structure can reduce how reliably LLMs retrieve and interpret content because of how information is chunked and processed.

The topic is useful, but fast-moving and increasingly mainstream. There is little value in reconstructing the presentation in greater detail now; it would be more efficient to research current guidance when the need becomes concrete.

## Presentation 2 — Miriam Lottner, Noma Security

The technical-writing function is likely to continue shrinking in headcount while expanding in scope. AI will increasingly handle repetitive production work, leaving greater value for technical writers who can:

- orchestrate AI-assisted content workflows
- exercise editorial judgment and quality control
- maintain consistency across a company’s technical content
- work beyond product documentation alone, including support, sales, marketing, and other customer-facing technical material
- establish the content function early in startups or stealth companies

This strongly supports the broader career direction already emerging: positioning not merely as a documentation producer, but as a senior content operator with cross-functional responsibility, source fidelity, editorial control, and AI workflow oversight.

## Networking

The event produced several new contacts, though none were hiring at the time. That still has value as network expansion, but it does not currently justify a major follow-up campaign unless one or two contacts stand out as strategically useful.
